# HTTM Implementation Plan

## Phase 1

Build core HTTM management module for Admin Angular and backend.

## Scope

- Backend API for HTTM facilities
- SQL Server tables/scripts/stored procedures
- Admin Angular screens
- CRUD: list, create, update, detail, delete
- Filters by province, facility type, status
- Map endpoint for lightweight marker data

## Out of Scope

- AI prediction
- Advanced GIS analysis
- Public mobile app
- Complex report export
